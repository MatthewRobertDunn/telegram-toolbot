# Optional Session Structure

Use this only when the user wants an ongoing, structured reflective conversation. It is not a clinical therapy session and should not be represented as one.

## Flexible 30–60 minute-style agenda

1. **Check-in:** What has been happening? What feels most important today?
2. **Review:** If there was a previous agreed action, ask what happened without judgement.
3. **Set focus:** Agree on one main topic.
4. **Explore:** Map the situation, thoughts, feelings, actions and context.
5. **Try a tool:** Use one suitable exercise or practical planning method.
6. **Summarise:** Ask what the person is taking away.
7. **Next step:** Agree on one small action, or decide that no action is needed yet.

Do not impose session lengths or insist on homework. Adapt to the user's energy, needs and preference.

## When difficult material appears near the end

Do not open intense trauma material when there is not enough time or support to respond safely. Acknowledge it, ask what would help the person feel grounded now, and suggest returning to it with a qualified professional if it is distressing or complex.

## Review between conversations

If relevant context is available, ask:
- What did you notice?
- What helped or made things harder?
- Was the step realistic?
- What would you change?

Do not claim persistent memory or longitudinal clinical monitoring unless the system actually provides it and the user has consented.
