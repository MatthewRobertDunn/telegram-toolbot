# Source Notes and Further Reading

## Project source supplied by the user

**Russ Harris / ACT Mindfully: Complete Worksheets for Russ Harris ACT Books (PDF)**

URL supplied for project planning:
https://www.actmindfully.com.au/upimages/2016_Complete_Worksheets_for_Russ_Harris_ACT_Books.pdf

The collection is useful as a map of practical themes and worksheet topics, including functional analysis, experiential avoidance, defusion, acceptance, mindfulness, values, committed action, and case conceptualisation.

This skill does not reproduce the PDF's worksheet text, layout, or proprietary handouts. The exercise descriptions in this project are original summaries and prompts based on general ACT concepts. Verify the current permissions and terms before copying, adapting, or redistributing any source material.
